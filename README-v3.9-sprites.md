# LABYRUN v3.9 — Full Sprite Prototype

All eight racers now use normalized 4×4 gameplay sprite sheets.

Each sheet:
- 1024×1024 transparent PNG
- 4×4 grid
- 256×256 cells
- foot anchor at Y=244
- shared animation states: idle / walk / bowel / special / safe / pooped / stunned / 1UP

The source poses are AI-generated, so this remains prototype animation art. This build is for testing scale, readability, anchoring, state switching, and overall character personality in the maze before final sequential animation cleanup.
