# LABYRUN v3.8 Sprite Prototype

Chili Willy now uses the first production-format 4x4 sprite sheet prototype.

- 1024x1024 transparent sheet
- 16 exact 256x256 cells
- normalized bottom/foot anchor
- idle, walk, bowel, special, safe, failure, stunned and 1UP states
- horizontal mirroring based on movement direction
- every other character still uses the existing puppet rig

This is intentionally a one-character prototype so animation scale/feel can be approved before creating the other seven sheets.
