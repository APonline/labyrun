# Character art

Drop future character art here.

- `portraits/` — character-select/menu art (WEBP recommended)
- `sprites/` — in-game sprites or sprite sheets (WEBP/PNG recommended)

Then point a character at the asset in `src/data/characters.js`, for example:

```js
portrait: 'assets/characters/portraits/taco-tony.webp',
sprite: 'assets/characters/sprites/taco-tony.webp',
```
